Lobster IT Limited - iXBRL Data Status

✅ What We Found:

Lobster IT Limited has the following iXBRL documents available:

  • 2017 Filing: 153,758 bytes of iXBRL data (application/xhtml+xml)
  • 2018 Filing: 123,437 bytes of iXBRL data
  • 2019 Filing: 130,423 bytes of iXBRL data
  • 2020 Filing: 135,069 bytes of iXBRL data
  • 2021 Filing: 134,500 bytes of iXBRL data

These files contain structured financial data in iXBRL format.

❌ The Problem:

The Companies House API structure has changed:

  1. The document-api endpoints return metadata (JSON) instead of actual document content when we request XHTML format
  2. The /content endpoint returns PDFs by default, even when iXBRL is available
  3. The public website (find-and-update.company-information.service.gov.uk) serves iXBRL correctly, but we can't access it due to CORS restrictions

⚠️ Current Behavior:

When you click the Finance tab for Lobster IT Limited:

  • The system tries multiple filings (2022, 2021, 2020, etc.)
  • Each filing has iXBRL data available (shown in metadata)
  • But the API returns PDFs or JSON metadata instead of the actual iXBRL content
  • Eventually falls back to showing minimal data for dormant accounts

💡 Solutions:

  1. Backend Proxy (Recommended):

    Set up a backend service that can:

    • Access the Companies House public website without CORS restrictions
    • Download the actual iXBRL files
    • Parse and return the financial data
  2. Use Different API Endpoints:

    Companies House may have other API endpoints that serve iXBRL directly

  3. Manual Download:

    Users can manually download iXBRL files from the Companies House website and upload them

✅ What's Working:

  • Successfully identifying which filings have iXBRL data
  • Correctly parsing the metadata to find document IDs
  • The parsing logic works when given actual iXBRL content
  • The Finance tab UI is ready to display the data
